### When not to use

- Do not put two Primary buttons in the same group. <small>([Figma 64:437](https://www.figma.com/design/q0faf7S1uuzwQo4UOe7bJq/Lemonade-Components?node-id=64-437))</small>
- Do not use Ghost for the main action on a screen. <small>([Figma 64:441](https://www.figma.com/design/q0faf7S1uuzwQo4UOe7bJq/Lemonade-Components?node-id=64-441))</small>
- Do not use a button to go to another page. Use a link. <small>([Figma 64:445](https://www.figma.com/design/q0faf7S1uuzwQo4UOe7bJq/Lemonade-Components?node-id=64-445))</small>
- Do not make it narrower than 172 or truncate the Label. <small>([Figma 64:449](https://www.figma.com/design/q0faf7S1uuzwQo4UOe7bJq/Lemonade-Components?node-id=64-449))</small>
- Do not hide the Label to make an icon-only button. <small>([Figma 64:453](https://www.figma.com/design/q0faf7S1uuzwQo4UOe7bJq/Lemonade-Components?node-id=64-453))</small>

### Best practice

- Write the Label as a short verb and noun, such as Submit claim. Change the height with the density mode on the frame, not by hand. <small>([Figma 64:459](https://www.figma.com/design/q0faf7S1uuzwQo4UOe7bJq/Lemonade-Components?node-id=64-459))</small>
