# Changelog

## 0.3.1

### Added

- Nothing.

### Changed

- Nothing in the component API. Props, exports, `styles.css` and `tokens.css` are unchanged since 0.3.0.

### Fixed

- Dialog Box: focus inside another open dialog is no longer pulled back, so open dialogs no longer fight over focus.
- Dialog Box: a server render while open returns nothing.
- Input: a swapped `Icon Right` now sits in the `input__icon` wrapper, so it takes the icon colours for its state, and it is hidden from assistive technology.

### Removed

- Nothing.
