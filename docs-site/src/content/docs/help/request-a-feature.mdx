---
title: Request a feature
description: Where to ask for a new component or change.
---

Feature requests go in GitHub Issues on this repository: [open the issues page](https://github.com/may-thet-htar-aung/lemonade-design-system/issues).

Every component starts as a Figma component set owned by the designer, so a new component or a new variant starts in Figma before it reaches code.
