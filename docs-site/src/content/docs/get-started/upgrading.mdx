<Aside type="caution" title="Nothing to upgrade from yet">
Only one version of the package, 0.1.0, has been published, so there is no earlier version to upgrade from. Each published version's changes will be listed in the [Changelog](/get-started/changelog/), sorted into added, changed, fixed, deprecated and removed.
</Aside>

When a newer version is published, install it with:

```bash
npm install @may_thet_htar_aung/lemonade-design-system@<version>
```

The package's React peer is `react` and `react-dom` `^19.0.0`.
