---
title: Upgrading
description: Moving from one published version of the package to the next.
---

Three versions of the package have been published, 0.1.0, 0.2.0 and 0.3.0. Each published version's changes are listed in the [Changelog](/updates/changelog/), sorted into added, changed, fixed, deprecated and removed.

To move to a newer version, install it with:

```bash
npm install @may_thet_htar_aung/lemonade-design-system@<version>
```

The package's React peer is `react` and `react-dom` `^19.0.0`.
