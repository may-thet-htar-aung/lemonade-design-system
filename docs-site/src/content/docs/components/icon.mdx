- It is never focusable: no tabindex and no interactive element. <small>([Icon.tsx:71](https://github.com/may-thet-htar-aung/lemonade-design-system/blob/b6932dedd65271031385b4c2af1242c2822a3676/src/components/Icon/Icon.tsx#L71))</small>
- When a text label sits next to the icon, leave Label empty and hide the icon from screen readers with aria-hidden="true". <small>([Figma 79:639](https://www.figma.com/design/AVDd45Hg9VOvZFgkykg9X3/Lemonade-Icons?node-id=79-639))</small>
- An icon on its own needs an accessible name. Set the Label property; code uses it as aria-label, such as "Search". <small>([Figma 79:642](https://www.figma.com/design/AVDd45Hg9VOvZFgkykg9X3/Lemonade-Icons?node-id=79-642))</small>
- Icons never take focus. Focus goes to the button or link that holds them. <small>([Figma 79:645](https://www.figma.com/design/AVDd45Hg9VOvZFgkykg9X3/Lemonade-Icons?node-id=79-645))</small>
- The 24 × 24 icon is not a touch target. Place it in a control of at least 44 × 44, such as Icon Button. <small>([Figma 79:648](https://www.figma.com/design/AVDd45Hg9VOvZFgkykg9X3/Lemonade-Icons?node-id=79-648))</small>
- Keep the icon at 3:1 or more against its background (WCAG 1.4.11). #2A313A passes on light surfaces, so override it on dark ones. <small>([Figma 79:651](https://www.figma.com/design/AVDd45Hg9VOvZFgkykg9X3/Lemonade-Icons?node-id=79-651))</small>
