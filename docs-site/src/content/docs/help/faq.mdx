## Why do some components have no page?

A component gets a page only when the board reads `Completed` or `Released` for it with a `Cleared` release verdict. [All components](/components/) lists every component with its status.

## Can I hardcode a colour or size?

No. Every CSS value is a semantic token. A value the design leaves unbound is a design gap, reported to the designer.
